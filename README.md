# Number Pop

A colorful bubble-popping and number-practice game, originally made together with my child.

## Run locally

Run `python3 -m http.server 8000 --directory public` and open http://localhost:8000. No dependencies or build step are needed.

Pop bubbles to increase the score. At surprise milestones, tap the number input and type the bouncing number to collect a prize. Tap empty space to change the background. Use the camera button to personalize bubbles; photos stay in your browser and are never uploaded.

Vercel serves the `public` directory.
